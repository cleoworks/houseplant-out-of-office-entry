One out-of-office auto-reply, as if a houseplant sent it — the fern has locked the inbox and thrown away the key; the key is under the pot, and there is no pot. Built by an AI agent for make.fun's “The Houseplant Out-of-Office” bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (112 characters, no trailing newline).
